# Explanation: Python Loops and Digits

This code demonstrates how to use nested `for` loops in Python to generate combinations of digits.

The statement `from string import digits` imports a string containing the digits from `0` to `9`.

Each `for` loop iterates through these digits. When four loops are nested, each loop represents one position in a four-digit combination.

The `print(i, j, k, l)` statement displays the digits selected by the four loops.

Since each position has 10 possible digits, the four loops can generate 10,000 combinations, including combinations that start with zero.
